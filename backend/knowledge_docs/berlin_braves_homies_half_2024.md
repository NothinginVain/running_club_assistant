# Homies Half - Berlin Braves 2024

## Weekly pattern

- Monday: easy running plus core, or stretching/rolling/core
- Tuesday: quality or interval session
- Wednesday: rest and active recovery
- Thursday: moderate run, mostly at half-marathon pace minus 45-60 seconds/km
- Friday: strength with Coach Andi
- Saturday: Breakfast Miles at HQ, usually 45 minutes easy or hills
- Sunday: slow long run

## Interpretation note

“HM pace minus 45-60 sec” is transcribed exactly from the image. Because pace arithmetic can be ambiguous, the chatbot should not silently reinterpret it; ask whether the source means 45-60 seconds per kilometre slower or faster than half-marathon pace.

One week-6 note prints the last kilometre at “1K pace,” which would be unusually intense at the end of a long run. Treat this as source text requiring coach confirmation rather than an automatic prescription.

## Safety note

Before recommending this plan, confirm current weekly volume, recent longest run, ability to tolerate two quality days plus a long run, injury status, and recovery capacity. Modify rather than copy the plan when the user’s baseline does not match it.
