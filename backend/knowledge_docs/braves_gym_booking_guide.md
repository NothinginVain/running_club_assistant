# Berlin Braves Gym Booking Guide

## How to book

1. Add your name to the required time slot and mark it with a colour.
2. Book every 30-minute block needed. For example, an 08:00–09:00 session requires both the 08:00 and 08:30 blocks.
3. If you cannot attend, free the reserved slot again.
4. Bring your own towel.

## Before leaving

- Make sure the cameras are turned on.
- Switch off the lights.
- Lock the door.

## Booking structure

- The timetable uses 30-minute slots.
- Listed times run from 05:00 through 00:00.
- Later versions of the sheet separate treadmill and gym reservations.
- Some periods contain blocked slots or facility activities, so the live sheet must be checked before visiting.

## Recurring activity

- Breakfast Miles appears regularly on Saturdays, usually in the morning.

## Data handling note

Individual member names and historical reservations were intentionally excluded. They are personal, temporary booking data and are unsuitable for long-term RAG ingestion. Use the live source sheet for current availability.
